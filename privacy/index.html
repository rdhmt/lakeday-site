Lewis (LakeDay) Privacy Policy

Last updated: November 18, 2026

Lewis is a private assistant operated by LakeDay Ventures for Ryan Hansen and accounts he authorizes. It is not offered to the public.

What it accesses. With the account owner's permission, Lewis reads Gmail messages and their metadata in authorized accounts. For its own mailbox only, it may mark messages read or archive them. It does not send, delete or share email from personal accounts.

How data is used. Email content is used only to summarize mail, flag items needing attention and create tasks for the account owner. It is not sold, used for advertising or used to train AI models.

Where data goes. Data is processed on LakeDay-controlled systems and by the AI model provider LakeDay uses to run Lewis, under that provider's terms. Nothing is shared with anyone else.

Retention. Lewis keeps short operational logs and task records. Sign-in tokens are stored on a LakeDay-controlled machine with owner-only file access.

Your control. You can revoke Lewis's access at any time at myaccount.google.com/permissions.

Google API data. Lewis's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
